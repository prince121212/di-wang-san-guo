# 会员第一版：开通操作与真机验收

第一版没有在线支付。邮箱会员与游戏账号是两套账号；不要把游戏密码提供给管理员。

## 管理员如何开通

1. 用户在新版APP右下角“Home”选择“邮箱注册”，获取验证码并自行设置密码，注册后登录。
2. 用户提供注册邮箱；管理员自行确认已收款，再打开 `https://dwpm-data.292828.xyz/admin/`。
3. “会员管理”输入完整邮箱查询，核对显示的邮箱、停用状态和到期时间。
4. 选择月卡30天、季卡90天或年卡365天，填写收款/开通备注，点击“开通 / 顺延续期”并确认。
5. 以返回的到期时间和操作记录为准。会员未到期从原到期日顺延；已到期从开通时开始计时。
6. 用户在APP点击“重新检查授权”，再启动游戏账号。同机最多启用两个游戏账号。

遇到请求超时：先查询同一邮箱核对操作记录，不要换套餐重复开通。原操作已成功时
页面会明确提示；结果仍不明时，页面恢复原套餐/备注，重试相同操作复用原编号。
未确认前不要清理浏览器会话存储或关闭标签页，否则会失去页面保存的待核对编号。

停用会暂停后续授权；“解除停用”不增加会员天数，用户需重新登录。
“撤销当前登录”不改会员到期时间；运行中的手机最迟在原两小时许可到期时检查到。

正式候选包：`app/build/outputs/apk/release/app-release.apk`。
正式签名和原内部Debug签名不同，不要为覆盖安装而卸载原APP或清理原数据。
候选包待下列验收通过后再对外分发。

电脑连接手机、允许USB调试与安装后，在自研辅助源码目录执行：

```sh
adb devices -l
adb install -r app/build/outputs/apk/membertest/app-membertest.apk
adb shell am start -n com.example.dwpmclone.membertest/com.example.dwpmclone.AssistantWebActivity
```

密码与邮箱验证码在手机自行输入，不要发送到聊天或写进日志。

## 必须完成的端到端检查

- 注册未开通：能登录会员，但不能启动游戏账号，提示联系管理员开通。
- 管理员开通：正确增加30/90/365天，原卡未到期则顺延；重新检查后可启动。
- 两个本机账号：可分别启动，第三个被明确拒绝。不要在原APP和验收包同时
  运行同一游戏账号；游戏动作验证前先停止原APP中对应的测试账号。
- 换手机：A手机先获授权，再在B手机主动登录同一会员。A保留原许可期间可
  继续运行（已接受的最长两小时窗口）；点击A的“重新检查授权”可立即验收
  失效提示，不能用这个操作代替两小时后台自动检查的独立验收。
- 挤下线：A显示另一手机与登录时间、明确暂停原因，前台弹窗不反复出现；
  有通知权限时后台也通知。A的旧续验/退出不能让B掉线，A不会自动用密码抢回会话。
- 到期、管理员停用、撤销、密码修改：原因分别准确，原本机账号/设置/记录保留。
- 断网：不误报别人登录；到检查时间无法验证则暂停，不延长原许可；联网后可重新检查。
- 进程重启：恢复时需联网验证，不能靠修改手机时间延长许可。
- 自动任务暂停后：不再发新游戏动作，未决账本保留；已确认且按配置需要撤防的
  矿队仅做限定收尾，不能冒充正常任务继续执行。
- 独立验证真实两小时后台检查、锁屏通知以及另一台手机的登录，不只看离线测试。
