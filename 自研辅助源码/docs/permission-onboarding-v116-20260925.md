# V0.0.116 权限引导与缺失配置恢复

## 问题证据

独立内部版最新启动请求日志显示真实游戏登录 SUCCEEDED，随后前台服务因通知权限、忽略电池优化缺失而停止。
前端将 stopped/未知状态错误归为“账号疑似掉线”。旧凭据缺失提示中的“删除后重新添加”会导致用户丢失账号配置。

## 修复

- 首次进入主界面，若基础后台权限缺失，显示用途说明，可选择“稍后设置”；已说明不在每次打开重复弹出。
- 原生后台权限引导页区分必要、可选、厂商人工核对项。逐项点击才打开系统权限入口；返回即刷新，不自动授予权限。
- 多次拒绝通知请求后可转到通知系统设置，不强行连着请求下一项权限。
- 普通账号启动在前端和原生层均增加权限前置检查；缺权限时不发送游戏登录请求，明确引导设置。
- stopped、checking、unknown、offline 分别显示正确含义，不把停用或未知状态当作掉线。
- 缺本机游戏凭据时引导“修改”补密码，明确不要删除原账号。
- 攻略、会员与购买入口不被后台权限门槛拦截；本轮不修改任何系统权限。

## 配置恢复

- 用户确认后，只补回内部版账号176缺失的11项功能配置及缺失的residentAutomationConfigJson。
- 现存配置不覆盖，保留当前账号身份、最新会话、新密码和会员登录。
- 恢复前两个待编辑数据文件备份到用户认证相关目录 restore-176-before（700目录/600文件）。
- 恢复后22项原配置值与迁移快照一致，凭据/会话/会员文件哈希不变。
- 恢复工具增加 restore-missing 子命令和幂等/不覆盖回归测试。
