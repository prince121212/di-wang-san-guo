# V111 会员状态同步与Home整理

## 根因与修改

1. 助手的“未登录”由空游戏账号列表生成，与会员登录无关，改为“游戏账号未添加”。
2. `会员到期 <日期>`原意是标记截止日期，却像过期警报。现在助手显示实际授权状态，
   Home独立显示“会员有效期至”。只有明确的MEMBER_EXPIRED且已有到期时间才说已到期；
   未开通、离线无法校验、会话被替换、停用分别显示，不能按手机时钟推断已授权。
3. 原来两个脚本都写expire-label，Home仅刷新该标签却不刷新会员暂停状态。
   新增纯展示模块membership-view.js，由Home与助手共同使用；授权渲染发出
   dwpm-membership-updated事件，助手立即刷新。较早的本地轮询回包不能覆盖新状态。
4. Home布局调整为页头、会员权益卡、本机授权操作、登录表单、开通续期说明、
   本机数据说明。保持攻略/助手/Home顺序和独立页面挂载，不改云端校验频率。
