# 独立内部版并存迁移

## 包标识

- 旧内部主包与正式发布包均为 com.example.dwpmclone，签名不同，不能直接互相覆盖。
- 新独立内部版：com.example.dwpmclone.internal，V0.0.115-internal，名称“帝三资料库·内部版”，沿用 debug 签名。
- 新内部版不使用游戏图标；游戏圆形图标仅 src/release 资源覆盖供正式包使用。
- APK：app/build/outputs/apk/internal/app-internal.apk。

## 本轮实际完成

- internal 构建、单元测试通过，已在手机安装，与原主包及membertest验收包并存。
- tools/migrate_internal_profile.py 从原主包读取账号公共元数据和普通功能配置，导出本地0600快照，拒绝已有数据的目标导入。
- 迁移3个账号、22项功能配置，以及3份residentAutomationConfigJson。
- 不复制会员会话、密码、密文凭据、设备私钥、自动任务运行态、未完成操作账本及云端缓存。
- 目标账号 enabled=false、sourceMode=0，需用户重新登录。功能配置原始字节与源快照一致，SHA256：56604d723fa2add6101fd0ed5890720b2dbe550c4328e12cef97a20c8555b236。
- 原应用没有卸载或清数据，原账户与配置保留。本轮原主包未被迁移工具写入。
- 新内部版启动后检测到会员已登录，但游戏账号仍全部停止，未代用户输入密码或启动游戏任务。
