# 单笔一分钱真实 APP 支付验收

这是生产环境真实资金验收，不是沙箱；需付款人本人在支付宝确认。
不更改正式月/季/年价格，不将 ALIPAY_LIVE_APPROVED 伪标为 true。

## 限制

- 仅在服务端设置 ALIPAY_ACCEPTANCE_MEMBER_ID（64位会员ID）、ALIPAY_ACCEPTANCE_PURCHASE_ID（固定UUID）、ALIPAY_ACCEPTANCE_UNTIL（毫秒截止时间）后可用。
- 新建和 SDK 调起只允许当前时刻后最多一小时的验收窗口。默认未配置，失败关闭。
- 原有设备签名、会员当前会话、请求防重放全部保留；同一账号在其他设备失效后也不能下单。
- 只能 app 渠道、month 参数、固定订单ID；实际商品为“支付验收（不开通会员）”，价格强制1分、时长0天。
- 重复请求复用订单。金额不接受客户端指定。普通套餐目录保持关闭。
- 回调与查单继续共用官方SDK验签、金额/应用/收款方核对；测试 flag 不得跳过支付校验。
- 窗口结束后停止签发订单串，保留配置以便接收迟到的已验签通知和查询/退款。订单记录永久区分 acceptance，绝不发放或扣减会员天数。
- 新客户端在真实付款确认页明确标注“¥0.01 真实支付验收、不增加会员”。

## 手机入口

独立 membertest 包保留主应用，debug-only `/api/member/payment-acceptance-create` 接收 purchaseId 后调用原有设备签名下单接口。
返回必须同时满足 acceptance=true、totalAmount=0.01、days=0 才允许继续；再用原有 payment-open 调起原生 SDK。
付款后的 payment-status 可读回真实结果；不自动支付，不自动退款。

当前主应用使用有效会员会话，验收包的同账号会话已被替换。为不挤掉主应用，验收需独立会员账号，由用户自行注册/登录；不要导出或复制现有登录令牌。
验收包包名/签名不同于正式应用，因此即便验收包付款通过，仍须正式签名 APK 的完整端到端验收；如支付宝因包名/签名拒绝，不能绕过平台校验。

上线时保留正式价格9.90/25.90/49.90，验收不等于正式会员发放已验证。
