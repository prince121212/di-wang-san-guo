## 已知问题

1. Android 当前仍是独立 Kotlin 业务核心，不能用测试绿色证明与电脑端逻辑完全一致。
2. 当前 `AssistantWebBridge` 使用全局单工作线程，长网络操作会阻塞本地接口。
3. 共享前端的手机桥固定等待 30 秒，真实网络操作超过 30 秒时会产生“核心响应失败”的假错误。
4. 真机逐功能、长时间锁屏、网络切换、进程恢复和重启恢复尚未完成最终验收。

上述问题是迁移要解决的对象，不属于基线失败。
