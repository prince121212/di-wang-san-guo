## 战斗核心模型（已确认/高置信）

### 1. 战场不是纯回合制，更像“行动蓄力/行动条”制

证据来自 `scriptBTList.sc` 与 `scriptBTEffect.sc`：

- 多个战法描述包含“当前蓄力值减少/增加”。
- BUFF 中有“蓄力暂停，持续#秒”。
- 战法触发条件里有“入坑后每10秒释放1次”。

因此战斗至少包含：

- 行动蓄力值
- 攻击速度/攻速
- 技能/战法可改变蓄力
- 某些状态可暂停蓄力

### 2. 目标策略已确认

来自 `sentence.txt`：

1. 最优攻击：选择能产生最好攻击效果的目标进行攻击。
2. 最强攻击：选择敌方部队中，单兵攻击输出最大的目标进行攻击。
3. 剿灭攻击：被攻击部队损失的兵数占该部队当前兵数比例最大。
4. 要害攻击：选择对方对自己攻击时产生最好攻击效果的目标进行攻击。
5. 城墙攻击：专门攻击城墙。

### 3. 战法/战斗技能体系已确认

新增解析文件：

- `bt_book_piece.md`: 35 个战法书/战法名称索引。
- `bt_list_summary.md`: 35 条战法/战斗技能记录。
- `bt_level_texts.md`: 战法多等级文本/公式描述。
- `bt_effects.md`: 25 条战斗 BUFF/状态效果。

战法触发条件包括：

- 普通攻击后概率触发
- 受到伤害后概率触发
- 入坑后每 10 秒释放 1 次
- 杀敌后概率触发
- 友军被击杀后概率触发
- 兵种限定触发：带步兵/弓兵/骑兵/战车
