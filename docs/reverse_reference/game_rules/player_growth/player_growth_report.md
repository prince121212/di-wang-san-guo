## 3. 官职、国家、战功与贡献

- 官职说明来自 `sentence.txt#424 di_说明官职`：
  - 丞相、大都督：仅次于国王，拥有招收成员、管理国库、外交、任命低级官职、发布榜文/宣言、添加游民等权利。系统国家中分别由贡献和战功最高者获取，每7日轮换一次；自建国家中由国王任命。
  - 尚书、中郎将：中流砥柱，拥有招收成员权利；按贡献和战功自动分配，每7日轮换；自建国家可人工调整。
  - 侍郎、都尉：低层官职，无特殊权利；按贡献和战功自动分配，每7日轮换；自建国家可人工调整。
- 国家征收：`sentence.txt#258` 明确只有国家官员可征收；都尉/侍郎每天2次，其他官职含国王每天5次；国库和征收者平分城池累积资源。
- 战功作用：拥有战功有机会获取国家官职，战功越高职位越高；也是百团争霸/国战无双任务排名标准之一。
- 战功获取：与敌国部队作战时，消灭敌人和损失兵力均可获得战功；攻陷野城和敌国城池也可获得战功。
- 战功衰减：当战功值超过等级值10倍后开始衰减；每天一次；衰减量=总战功×衰减比例；基础1%，连续未登录天数每增加1天，附加值+1%。
- 贡献获取：国库捐献资源、捐献国家科技积分、徒弟升级、修筑城墙/道路/炮塔均可获得贡献。
- 贡献衰减：当贡献值超过等级值100倍后开始衰减；每天一次；基础1%，连续未登录天数每增加1天，附加值+1%。

- FAQ 补充：若战功和贡献均为国家排名最高，官职轮选时优先进入战功最高的官职。
- 师徒贡献补充：师傅通过徒弟升级获得贡献累计到 1万 后，只有战功值超过100的徒弟升级才继续给贡献；累计到 10万 后，只有战功值超过1000的徒弟升级才继续给贡献；累计到 50万 后，不再获得徒弟升级贡献奖励。
- 寨主称号战功补充：寨主称号使灭敌时获得的战功增加10%，但仅增加“击败玩家兵力”产生的战功，不增加攻打城池固定战功。

## 4. 国库、军团、建国

- 国库来源：攻打城池、国家城池税收、国民捐献。
- 国库用途：国家科技提升、国家官员俸禄、国民援助。
- 国库分配权：国王、丞相、大都督可分配国库资源。
- 国库捐献等级门槛：君主等级需超过30级。
- 国库每日接受捐献上限：铜钱1.5亿、粮食3亿；其中铜钱捐献可增加国库铜钱上限1亿，黄金捐献可增加5000万。
- 国库总上限：铜钱100亿、粮食300亿。
- 军团创建条件：创建者等级35级以上，缴纳30万铜币，军团名不能重复。
- 建国条件：建国者不能是国王；至少1个玉玺；拥有一座归属自己的且规模至少为县城的城池；需1000万铜钱及玉玺/虎符/印绶/令牌等道具。
