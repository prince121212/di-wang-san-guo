帝王三国电脑版辅助 Windows 便携版使用手册
========================================

一、适用环境

1. Windows 10 或 Windows 11，64 位系统。
2. 不需要安装 Python、Clash Verge 或其他运行库。
3. 程序只监听本机 127.0.0.1，局域网里的其他电脑无法直接访问。


二、首次使用

1. 把整个 ZIP 文件复制到 Windows 本机磁盘，例如“下载”目录或 D:\DWPM。
2. 右键 ZIP，选择“全部解压”。不要直接在压缩包里运行文件。
3. 不要在 SMB 网络共享目录中直接运行，以免 SQLite 数据或代理进程受网络波动影响。
4. 双击“启动辅助.bat”。
5. 保持弹出的黑色运行窗口开启。浏览器会自动打开：
   http://127.0.0.1:17351/index.html
6. 在页面中添加账号、选择区服并设置任务。

若浏览器没有自动打开，可手动复制上面的地址到浏览器。


三、正常关闭

优先双击“关闭辅助.bat”，等待提示完成后，再关闭黑色运行窗口。

不要在任务执行或 SQLite 写入时直接关机。意外断电后 SQLite 通常可以自行恢复，
但正常关闭更稳妥。


四、IP 节点说明

1. 辅助使用 proxy 目录里的独立 mihomo.exe 和“顶级机场-完整便携版.yaml”。
2. 它不会切换 Windows 上 Clash Verge 的当前节点，也不会修改系统代理。
3. 浏览器和其他软件仍使用它们原来的网络线路。
4. 辅助页面中的节点只作用于游戏请求，并会显示最近实测的出口公网 IP。
5. 同一个机场节点如果采用动态出口或负载均衡，公网 IP 仍可能发生变化。
6. 当前 YAML 是固定快照，不会自动更新订阅，并且含节点认证信息，请勿公开上传。


五、数据保存

所有 Windows 端数据都保存在当前 Windows 用户的固定目录：

%LOCALAPPDATA%\DWPMDesktop\data

包括：

- 账号和设置 SQLite 数据
- 日志
- 山贼地图与资源地图
- 独立代理运行文件

程序版本目录和用户数据目录相互独立。以后把新版解压到任何本机目录，
仍会自动读取原来的账号、密码、区服、游戏平台和完整任务配置。

从 V0.0.1 首次升级时，新版会优先读取自身目录下的旧 data，也会自动查找
同级旧版本目录中最近使用且完整的 SQLite 数据库，然后复制到固定数据目录。
旧版原始 data 不会被删除。

数据库结构升级前，程序会自动在以下目录保留最近 5 份一致性备份：

%LOCALAPPDATA%\DWPMDesktop\data\database_backups

这些数据不会与 Mac 自动同步。不要同时在 Mac 和 Windows 上运行同一个游戏账号，
否则可能造成重复登录、任务重复或游戏会话冲突。

手动备份时先关闭辅助，然后复制上述固定 data 文件夹即可。


六、以后更新

1. 双击旧版“关闭辅助.bat”。
2. 把新版 ZIP 解压到本机的新目录。
3. 双击新版“启动辅助.bat”。

账号和完整配置会从固定数据目录自动恢复，不需要复制 data，也不需要导入导出。
新版若修改 SQLite 结构，会先自动备份，再逐版本事务升级；升级失败会回滚，
不会用空数据库覆盖旧数据。

不要把正在使用的 SQLite 文件放在 SMB 共享目录中运行。


七、常见问题

1. 双击后提示缺少 mihomo.exe
   Windows 安全中心可能隔离了代理核心。打开“保护历史记录”确认后恢复文件，
   并仅对这个可信的便携版目录添加排除项。

2. Windows SmartScreen 阻止批处理或程序
   确认文件来自本次 Mac2win 共享交付后，选择“更多信息”再允许运行。

3. 页面提示端口 17351 被占用
   先双击“关闭辅助.bat”。仍未解决时，关闭旧的“帝王三国电脑版辅助”黑色窗口，
   再重新启动。

4. IP 节点不可用
   先确认 Windows 本机能正常上网，再查看
   %LOCALAPPDATA%\DWPMDesktop\data\helper_mihomo\mihomo.log。
   机场节点本身失效时，需要更换新的完整 YAML 快照。

5. 页面打不开
   确认启动窗口仍在运行，然后访问 http://127.0.0.1:17351/api/health。
   若无响应，查看启动窗口的错误信息以及
   %LOCALAPPDATA%\DWPMDesktop\data\logs 目录。

6. 需要向开发者反馈
   先关闭辅助，再打包
   %LOCALAPPDATA%\DWPMDesktop\data\logs 和
   %LOCALAPPDATA%\DWPMDesktop\data\helper_mihomo\mihomo.log。
   日志可能含账号相关信息，只通过可信渠道传递。


八、目录说明

app       电脑版辅助源码、网页和业务资源
data      仅用于首次继承 V0.0.1 旧数据；新版数据存入固定用户目录
proxy     Windows 独立代理核心、机场 YAML 和地理规则数据
runtime   随包附带的 Python 运行时

启动辅助.bat       启动后端并自动打开页面
关闭辅助.bat       正常停止后端和独立代理
portable_launcher.py 启动入口，请勿删除
