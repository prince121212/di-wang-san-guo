使用说明

                

                  
出征将领坑位

                  
您勾选出征将领的顺序决定将领的坑位，逻辑与原服中相同，即最先勾选的将领将会占据首排居中的坑位。

                

              


              

                

                  
                  

                    
从出征到开箱

                    
当前服务器开放 7 章，共 86 关

                  

                


                

                  当前服务器资料
                  
副本是连续的单人战斗玩法。辅助会按所选章节和关卡发起战斗，等待战斗结束，再按设置打开左、中、右其中一个宝箱。

                


                

                  
出征前检查

                  
    
                    
  1. 出征将领必须处于“闲”状态，征、修、战等其他状态均不能出征。
    2. 
                    
  2. 将领必须已经配兵；无配兵时副本不会启动。
    3. 
                    
  3. 在“军事 - 副本”勾选规则，选择将领、章节、关卡和开箱位置后保存。
    4. 
                    
  4. 任务栈空闲时会立即执行；已有任务时按队列顺序等待。
    5. 
                  

                


                

                  
战斗与开箱

                  

                    
战斗形式单人副本

                    
开箱位置左 / 中 / 右

                    
完成记录成功结算后次数 +1

                    
每日重置每日 0 点归零

                  

                  
左、中、右箱目前没有可靠证据证明某一位置的奖励概率更高，按自己的习惯选择即可。已实测第一章第 3 关使用右箱可正常完成，战斗约 137 秒。
