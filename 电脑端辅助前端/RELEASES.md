## V0.0.3 - 2026-07-15

- 交付文件：`帝王三国电脑版辅助-Windows-V0.0.3-20260715.zip`
- SHA-256：`0c4dbe44fe2234d016cb450c80d22a060dbe8dbd23b6125d112f678e87b896c7`
- 修复 0x8004 将领记录的低位 ID 被错误过滤的问题。
- 兼容将领名称记录与记录体内 ID 错位的真实响应。
- 兼容兵力表两个关联 ID 不相等的真实响应，恢复步1、灰1等将领的配兵。

- 独立 Mihomo 配置自动补充 352 区游戏服务器的代理规则，不覆盖用户既有节点选择。
- 代理节点下拉框按运行中账号的公网 IP 占用数量标色。

## V0.0.2 - 2026-07-15

- 交付文件：`帝王三国电脑版辅助-Windows-V0.0.2-20260715.zip`
- SHA-256：`424f51529b2417d7c8025ecf6bb515e52001db57e1918a170601025638866e0e`
- 角色-任务页的副本常驻任务增加当天副本次数显示。
- 增加只读取本地缓存与 SQLite 的全账号总控页面，不新增游戏服务器请求。
- 常规-常用设置改为默认开启治疗伤兵、默认关闭升级科技。
- 总控账号列表在角色名后显示所在国家简称。
- 网络型心跳连续失败 3 次后自动换 IP，最多换 2 次；仍失败则按网络掉线等待 3 分钟重连，每个公网 IP 最多同时登录 2 个账号。
- 修复首次打开且尚无账号时不读取代理节点的问题。
- Windows 新版统一使用 `%LOCALAPPDATA%\DWPMDesktop\data` 保存用户数据，首次升级自动继承当前目录或同级旧版本的有效数据。
- SQLite 增加结构版本、逐版本事务迁移、升级前自动备份、失败回滚和高版本数据库防降级保护；不增加手动导入导出。
- 沿用 V0.0.1 的独立 Python 运行时、Mihomo、机场 YAML、业务映射和中文使用手册。

## V0.0.1 - 2026-07-15

第一个正式版本基线，以本次交付到 Windows 电脑的便携包为准。

- 交付文件：`帝王三国电脑版辅助-Windows-20260715.zip`
- SHA-256：`b08d2d820154cc28e6d453782fca34d4074e8235721e5975b1d98dc94fdda570`
- 内置独立 Mihomo、Python 运行时、机场 YAML、业务映射和中文使用手册。
- Windows 数据使用本机 SQLite，与 Mac 数据相互独立。
- 包含打矿编队部分将领败退、部分将领驻守时的自动召回修复。
- 包含召回响应变化时通过“防→返/闲”状态确认召回成功的兼容逻辑。
